# park: このセッションを閉じてよいか

対象は **このセッションだけ**。動いている全セッションの棚卸しは `/wip` を使う。

## 1. 事実を集める

会話の記憶に頼らず、手元の状態を確かめる。このセッションで触ったリポジトリ（cwd 以外も、
会話中に編集・commit したもの全部。worktree も含む）それぞれについて:

- `git status --short` — 未コミットの変更
- `git log --oneline @{u}..` — 未 push のコミット（upstream が無いブランチは、それ自体が未 push）
- `gh pr list --author @me --state open --json number,title,headRefName,url` — 開いたままの PR
  （このセッションで作った・触ったものだけを拾う）
- `git worktree list` — このセッションで作って片付けていない worktree

あわせて会話を振り返る:

- 走っているバックグラウンドのコマンド・サブエージェント・定期実行（`/loop` など）
- ユーザーに質問・確認を投げたまま返事をもらっていないもの
- 自分で「次は〜」「あとで〜」と言ったまま手を付けていないもの
- 再起動後や別日に確かめる約束をしたもの

## 2. 判定する

| 判定 | 条件 |
| --- | --- |
| 🔴 まだ閉じない | バックグラウンド処理が実行中。未コミット・未 push の変更がある。ユーザーへの質問が宙に浮いている |
| 🟡 閉じてよいが続きがある | 手元は片付いているが、PR のマージ待ち・確認待ち・次の作業が残っている |
| 🟢 閉じてよい | 依頼が完了していて、続きの話が無い |

迷ったら 🟡 に倒す。

## 3. 閉じる前の後片付け

- 🔴 の原因が片付けられるものなら、片付けてよいかを聞く（未 push の commit を push する等）。
  勝手に破棄・強制操作はしない。
- 🟡 で対象リポジトリがある場合は、dotfiles の `rules/work-status.md` に従って
  そのリポジトリの `docs/STATUS.md`（リポジトリ固有の置き場所があればそちら）に
  「現在地・次のアクション・保留」を書き、commit して push する。
  - 作業ブランチがあればそこに積む。main しか無く main 直 push が禁止なら、ブランチを切るか
    ユーザーに確認する。
  - 公開リポジトリかどうかを確かめ、公開なら個人的な事情は書かない。
- 対象リポジトリが無い作業なら、memory の索引に 1〜2 行残す。
- STATUS.md もメモも不要なほど小さい続き（「PR マージして」だけ等）は、書かずに報告だけでよい。

## 4. 報告する

日本語で、短く:

1. 判定（🔴 / 🟡 / 🟢）と、その理由を一言
2. 残っていること（箇条書き。無ければ「なし」）
3. 後片付けでやったこと（STATUS.md を更新して push した、など）
4. 戻り方: `claude --resume <セッションID>`（ID は `echo $CLAUDE_CODE_SESSION_ID` で取れる）。
   STATUS.md に書いたなら「新しいセッションからでも STATUS.md を読めば続けられる」と添える。
